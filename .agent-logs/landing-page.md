# Session Entry: Adding the Landing Page

The landing page was reintroduced at reduced scope late in the build. The main generation interface used to be hosted at `/`, but to ensure a stranger opening the live link cold benefits from a clear first impression, we've moved the generation interface to `/create` and established a clean landing page at `/`.

## Scope Decisions
- **Clean Focus:** Deliberately built to be cleaner than the original higgsfield.ai homepage. Instead of a busy grid of models, APIs, and plugins, the page is focused on one clear headline ("Endless new visions. One upload in.") and a single, prominent call-to-action ("Start Creating ✦").
- **Visuals:** Reused the existing dark theme and neon-lime accent tokens established earlier.
- **Complexity limits:** Omitted any feature grids, cards, or unnecessary sections. Kept the page lightweight to adhere to a strict time-box.
